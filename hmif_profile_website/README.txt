WEBSITE PROFIL HMIF BEM FT-UMJ — FILE TERPISAH

Struktur:
- index.html : struktur halaman website
- css/style.css : desain dan mode gelap/terang
- js/main.js : navigasi, tema, pencarian/filter, animasi
- assets/ : logo dan foto

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder dengan VS Code.
3. Jalankan index.html menggunakan Live Server atau buka langsung di browser.
4. Jangan memindahkan index.html dari folder CSS, JS, dan assets.

Visi dan misi:
Teks dimasukkan lengkap sesuai ART HMIF BEM FT-UMJ MTA 2025–2026 Pasal 20 dan 21.
Makna logo mengikuti ART Pasal 14.
Arah program umum diringkas dari GBHH MTA 2025–2026.

Catatan:
Nama/NIM pada struktur adalah berdasarkan informasi yang tersedia dalam contoh struktur yang dikirim. Beberapa nama staf, bendahara, dan MPH masih perlu diperiksa serta dilengkapi berdasarkan SK kepengurusan 2026–2027. Contoh program kerja bukan klaim program resmi yang sudah disahkan.

Pembaruan: foto utama BPH HMIF BEM FT-UMJ periode 2026–2027 berada di assets/bph-2026-2027.jpg.

Pembaruan: struktur menampilkan satu Sekretaris dan satu Bendahara; Ketua dan Wakil Ketua dipisah jelas. Foto terbaru ditempatkan khusus untuk Departemen Kominfo. Bagian Departemen & Jobdesk dan Program Kerja yang Berdampak dihapus sesuai permintaan.

Pembaruan perbaikan tampilan:
- Navigasi Departemen dan Program Kerja dihapus karena kedua bagian tersebut dihapus sesuai instruksi.
- Semua foto galeri (termasuk foto BPH periode 2026–2027) memakai ukuran kartu yang seragam.
- Foto baru Departemen Kominfo dipakai hanya pada kartu Kominfo.
- JavaScript diperbaiki: filter departemen yang elemennya sudah dihapus tidak lagi menyebabkan error yang membuat halaman kosong.

Pembaruan terbaru:
- Bagian Struktur Organisasi dihapus seluruhnya, termasuk tautan navigasinya.
- Galeri BPH disusun ulang dengan ukuran kartu foto yang sama.
- Foto Departemen Kominfo yang baru diunggah digunakan untuk kartu Departemen Kominfo, bukan untuk kartu BPH.
- Ketua Himpunan, Wakil Ketua Himpunan, Sekretaris, Bendahara, dan departemen ditampilkan sebagai kartu galeri seragam.
